## Code Style

Follow the canonical Spring Boot 3 rules below. Each one-liner has a full source
under `engineering-standards-central/source/`. Full bodies ship to Cursor, Copilot,
Claude, and Junie.

- Mandatory @Valid and @Validated on Controller Boundaries.
- Mandatory Request and Response Record Types at the Controller Boundary.
- Prohibition of Generic Runtime Exceptions.
- Prohibition of Blind/Generic Catch Blocks.
- Unified ApiErrorResponse Contract for All REST Error Pathways.
- EntityGraph Over JOIN FETCH for Pagination-Safe Eager Loading.
- Mandatory Pageable on All List-Returning Repository Methods.
- Mandatory Pageable Defaults on Controller List Endpoints.
- N+1 Select Prevention via Fetch Strategy and BatchSize.
- Disable Open-Session-In-View.
- Disciplined @Transactional Boundaries — No External I/O Inside Transactions.
- Prohibition of Self-Invocation Across Transactional Proxy Boundaries.
- Read-Only Default at the Service Class Level.

## Testing

and repository layers; reserve `@SpringBootTest` for end-to-end and Testcontainers
integration tests. The Phase-6 ArchUnit fixtures enforce the Logic Holes at build time.
